Solutions are written for the standard LeetCode submission environment (`Solution` class). To test them locally, wrap the solution in a simple driver program with a `main` function:

```cpp
#include <iostream>
// Include the solution file or paste the class here

int main() {
    Solution solution;
    // Call solution method with test inputs
    return 0;
}
```

Compile using any modern C++ compiler (C++17 or C++20 recommended):

```bash
# Using g++
g++ -std=c++20 -O2 "1 Tow Sum.cpp" -o solution
./solution

# Using clang++
clang++ -std=c++20 -O2 "1 Tow Sum.cpp" -o solution
./solution
```
